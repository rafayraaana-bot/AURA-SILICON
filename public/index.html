One platform for semiconductor engineering.

The built-in RTL preview is limited; physical-design runs use a separately configured local OpenLane toolchain.

RTL & HDL workflow

Browser RTL editor, project files, immutable source snapshots, source-located diagnostics, and a limited module/port/declaration/continuous-assignment parser.

Compiler & AURA IR

Versioned JSON IR output is deterministically hashed and stored as a content-addressed artifact. AURA has no native netlist optimizer; a local OpenLane run can produce a synthesized netlist after setup.

Physical design

The workspace can launch its local OpenLane 2 + SKY130 flow for floorplanning, placement/routing, and GDSII. Physical-design jobs are optional and do not block RTL editing or compilation. Results are downloadable only after real final artifacts are verified; congestion/signoff validation is not claimed.

What works today—and what remains.

RTL compilation works independently. Optional physical-design jobs use the local OpenLane 2 + SKY130 flow when it is available on this machine.

Design mode

Project files, an RTL editor, immutable versions, compilation controls, and source-located parser diagnostics.

Physical design mode

OpenLane execution is integrated in the workspace and runs locally through WSL 2 with OpenLane 2 + SKY130. AURA reports no physical result unless a real run verifies final GDSII and netlist outputs; it does not claim congestion or signoff validation.

Visualization mode

The authenticated physical-layout viewer offers an orbitable 3D exploded-layer view and a 2D top-down view of real polygons extracted from verified GDSII. It stays empty until a completed RTL-backed OpenLane run provides that artifact.

Plans configured for engineering teams.

Pricing and plan limits load from the AURA backend. The current preview has no payment provider, so subscriptions cannot be purchased.

Security integration status.

Email/password accounts, configurable GitHub and Google OAuth, and basic organization-scoped API access are implemented. SAML, fine-grained RBAC, and production session controls are not.

Identity

Email/password sign-in is available. GitHub and Google sign-in activate when the API administrator configures their OAuth clients. Password recovery and SAML sign-in are not available.

Artifact security

AURA IR files use SHA-256 content-addressed storage and organization checks. Project-level membership ACLs are not implemented.

Observability

Jobs expose persisted stage/status/log records. Distributed tracing, worker telemetry, and streaming events are not implemented.
