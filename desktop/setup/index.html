AURA SILICON
DESKTOP ENGINEERING WORKSPACE

Connect to AURA SILICON

This desktop app signs in to the AURA service configured for this release, then opens your web workspace. If no service is configured, enter its API base URL once; the app saves it for future launches.

Secure HTTPS is required. HTTP is allowed only for localhost development.

Native desktop capabilities Native folder selection · protected project import · confirmed project export · file-change alerts · operating-system secure storage (Linux requires a supported desktop keyring)

This client does not provide an AI hardware agent, simulation, synthesis, physical design, GDSII or 3D chip rendering.
